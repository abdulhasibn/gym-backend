Gym SaaS

Production MVP blueprint for invite-only joins, base + addon billing, client-owned fitness data with consent grants, renewals, coaching, and the member app.

API live today: Auth · Gym orgs · Mini-CRM · Plans · Membership invites · Client accept + DataGrants. See Orbit for build status.

01 — Account lanes

Two doors, no crossover

Signup locks a lane. Client accounts never become staff; staff never claim membership invites.

Lane

CLIENT

Signup as member. Affinity to a gym only after an Admin membership invite.

  • Own profile & grants
  • Own attendance check-in
  • Read coaching assigned to them

Lane

STAFF

Signup as staff (gets a staff code). Progress Unassigned → Trainer or Admin via invite, or Admin by creating an org.

  • Create first GymOrg
  • Accept staff invite
  • Tenant-scoped ops after affiliation
